# Review Entrypoint

Route review tasks by object:

- papers or drafts: `paper-review`
- writing a Mathematical Reviews/MathSciNet or zbMATH bibliographic review:
  `draft-writing` with `mathscinet-zbmath-review-style.md`; do not infer that a
  local or user-provided item was supplied by the reviewing service
- annotated review only when annotation is explicitly requested:
  `annotated-review`
- code changes: code-review persona or project review workflow
- final research reports: `research-report-reviewer`

Findings should lead, with evidence and test gaps stated explicitly.
